
# Day 21 - Responsive Navigation Bar

## Description

A responsive navigation bar built using HTML, CSS, and JavaScript. The navigation links appear horizontally on desktop screens and collapse into a hamburger menu on smaller screens.

## Objective

Practice responsive web design, CSS media queries, transitions, and JavaScript toggle interactions.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive desktop navigation bar
- Hamburger menu for mobile devices
- Smooth menu opening and closing transitions
- Animated hamburger icon
- Active navigation link styling
- Automatic menu closing after selecting a link
- Responsive hero section
- Modern dark user interface

## Project Structure

```text
day-21-responsive-navbar/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Resize the browser window to test the mobile navigation.
5. Click the hamburger icon to open or close the menu.

You can also open the folder in Visual Studio Code and run it using the Live Server extension.

## Learning Outcomes

- Understanding CSS media queries
- Creating responsive navigation layouts
- Using JavaScript class manipulation
- Handling click and resize events
- Adding CSS transitions
- Improving basic navigation accessibility
